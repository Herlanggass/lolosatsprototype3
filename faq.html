Pertanyaan Umum (FAQ)

Berapa ukuran dan format file maksimal yang bisa diunggah ke sistem?

Sistem hanya menerima berkas berformat .PDF dengan ukuran maksimal 5MB. Pastikan file Anda telah sesuai sebelum mengunggah.

Mengapa muncul pesan "Format File Tidak Sesuai"?

Pesan error tersebut muncul jika Anda mengunggah file selain format .PDF (seperti .docx, .png, atau .jpg), atau jika ukuran file Anda melebihi batas 5MB.

Bagaimana cara mengecilkan ukuran file PDF yang terlalu besar?

Anda dapat menggunakan alat kompresi PDF daring (online PDF compressor) gratis untuk menurunkan ukuran berkas tanpa mengurangi kualitas teks secara signifikan.

Apakah saya bisa memperbarui file CV atau dokumen yang sudah diunggah?

Bisa. Anda dapat mengunggah ulang dokumen baru selama periode pendaftaran atau pengajuan masih dibuka oleh sistem.
